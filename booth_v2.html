# GitHub Copilot Instructions for リポジトリB

## TypeScript Style Guide

**Must follow [TypeScript Deep Dive Style Guide](https://basarat.gitbook.io/typescript/styleguide):**

- Use **named exports** (no default exports)
- Use **union types** instead of `enum`
- Use **`unknown`** instead of `any`
- Use **`type`** instead of `interface`

## File Naming Convention

**Follow [Angular Coding Style Guide](https://angular.io/guide/styleguide):**

- All file names use **kebab-case**
- Examples: `xxx-yyy.ts`, `xxx-yyy.spec.ts`

## Coding Rules

- Add **1 blank line at end of file** (mandatory)
- Use **object shorthand**: `{ foo }` not `{ foo: foo }`

## Module Boundaries

- Respect Nx `@nx/enforce-module-boundaries` rules
- Scopes: `lock`, `wall`, `zell`, `shared`
- Types: `application`, `feature`, `util`, `shared`

## Commit Message Format

- Root: `<type>: <message>`
- Lock/Wall: `<semantic-version>-<type>(scope): <message>`
- Plugin: `<type>(plugin): <message>`
